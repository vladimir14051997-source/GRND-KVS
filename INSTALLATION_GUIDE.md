# Установка GRND.GG Жалобы на мобильные устройства

## Для Android (Chrome):

1. Откройте Chrome на устройстве
2. Перейдите на страницу расширений Chrome: `chrome://extensions/`
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с расширением
6. Расширение установлено!

## Для создания ярлыка на рабочем столе (PWA):

1. Откройте Chrome на телефоне
2. Перейдите на https://grnd.gg/admin/complaints
3. Нажмите на меню (три точки)
4. Выберите "Установить приложение" или "Добавить на главный экран"
5. Нажмите "Установить"
6. Теперь на рабочем столе появится ярлык приложения

## Для iOS (Safari):

1. Откройте Safari
2. Установите расширение через браузер "Orion" (поддерживает Chrome extensions)
3. ИЛИ используйте PWA версию:
   - Откройте https://grnd.gg/admin/complaints в Safari
   - Нажмите "Поделиться"
   - Выберите "На экран "Домой""
   - Нажмите "Добавить"

## Настройки для лучшей работы:

1. Разрешите уведомления в браузере
2. Отключите энергосбережение для браузера
3. Разрешите фоновую работу приложения
